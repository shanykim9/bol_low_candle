# 볼린저밴드 + 저점캔들 돌파 양봉 자동매매

키움증권 REST API를 이용한 **볼린저밴드 하단 + 240일선 저점캔들 돌파 양봉** 전략의 실시간 자동매매 및 백테스트(시뮬레이션) 프로그램입니다.  
Streamlit 웹 UI로 파라미터 설정, 종목 관리, 결과 분석을 한 화면에서 수행할 수 있습니다.

**엔진 버전:** `20260726-v14`

---

## 주요 기능

| 구분 | 기능 |
|------|------|
| **실시간 자동매매** | 다종목 동시 모니터링, 상태 머신 기반 분할 매수·익절·손절 |
| **시뮬레이션** | 과거 일봉 백테스트, 종목별 요약·포트폴리오 자금 분석 |
| **종목 입력** | 종목코드/종목명 직접 입력, 또는 종목명 `.txt` / `.md` 업로드 |
| **종목 변환 캐시** | 동일 파일·동일 종목으로 조건만 바꿔 재실행 시 종목명→코드 변환 생략 |
| **시세 구분** | KRX 정규장 / 통합시세(KRX+NXT) |
| **탐색 기간** | 상대기간(6개월 단위, 최대 10년) 또는 특정 년·월 구간 |
| **240일선 필터** | 디폴트 / 240선추세(3·7·10·20일 연속 상승) |
| **자금 분석** | 최대 동시 투입자금, T+3 결제 반영 권장 계좌, 자금투입대비 순손익률 |
| **결과 다운로드** | CSV · Excel(`.xlsx`) — 종목별 요약 + 거래 상세 |

## 사용 방법

### 실시간 자동매매

1. 사이드바 **운영 모드** → `실시간 자동매매`
2. 종목 직접 입력 후 **종목 확인**, 또는 `.txt` / `.md` 업로드
3. 시세·지표·투자금액·손절·익절 설정
4. **▶ 시작** → 종목별 상태·이벤트 로그 확인
5. **■ 중지** 로 종료

### 시뮬레이션 (백테스트)

1. 사이드바 **운영 모드** → `시뮬레이션`
2. 종목 확인 또는 종목명 파일 업로드
3. **▶ 시뮬레이션 실행**
   - 파일 업로드: 종목명 → 종목코드 자동 변환
   - 동일 목록 재실행 시 변환 생략
4. 결과 확인
   - 종목별 요약
   - 포트폴리오 자금 분석
   - 거래 상세
   - **CSV / Excel** 다운로드

### 종목명 파일 형식 (.txt / .md)

```
삼성전자
SK하이닉스, NAVER
카카오; 현대차
```

한 줄·쉼표·탭·세미콜론 구분 가능. **종목명**을 입력합니다.

## 전략 요약

### 저점캔들

| 조건 | 내용 |
|------|------|
| 240일선 | 저가 ≥ 240일 이동평균 (필수) |
| BB하한 | 시가·고가·저가·종가 중 **하나라도** 볼린저밴드 하한 **이하** |
| 양·음봉 | **무관** |
| 240선추세(옵션) | MA가 N일(3/7/10/20) 연속 상승 |
| 탐색 기간 | 상대기간(최대 10년) 또는 특정 년·월 |

### 기준캔들

| 조건 | 내용 |
|------|------|
| 시점 | 저점캔들 **바로 다음 거래일** |
| 양봉 | 종가 > 시가 |
| 돌파 | 종가 **>** 저점캔들 고가 (같으면 탈락) |

### 매매 규칙

| 항목 | 내용 |
|------|------|
| 매수 Case A | 기준캔들 거래량 > 저점캔들 × 300% → 즉시 1차 매수 |
| 매수 Case B | 기준캔들 거래량 ≤ 저점캔들 × 300% → 2·3차 분할 매수 대기 |
| 매수포기 | 대기 중 현재가 > 저점캔들 저가 × (1 + abandon%) |
| 손절 | 기준저가 또는 1차 매수가 대비 -5/10/15% |
| 1차 익절 | 평균단가 대비 +15~50% (5% 단위) → 50% 매도 |
| 2차 익절 | 평균단가 대비 +20~60% (5% 단위, 1차보다 높음) → 잔여 매도 |
| 트레일링 스탑 | 최근 익절가 대비 -5% 하락 → 잔량 전량 매도 |

볼린저밴드는 영웅문4와 동일하게 **모집단 표준편차(ddof=0)** 를 사용합니다.

## 시뮬레이션 결과

### 종목별 요약

신호 수, 매수 발생, 평균 손익률, 승률, 수익·손실·순손익 금액 등

### 거래 상세 컬럼

종목코드, 종목명, 저점캔들발생일, 기준캔들발생일,  
1차·2차·3차매수가, 매수평균가,  
손절일, 손절가, 1차익절일, 1차익절가, 2차익절일, 2차익절가,  
트레일링스탑발동, 최종손익률, 투자금액, 손익금액

### 포트폴리오 지표

| 지표 | 설명 |
|------|------|
| 최대 동시 투입자금 | 기간 중 동시에 묶인 매수금의 최대값 |
| 권장 계좌 잔고 | T+3 거래일 결제 대기 반영 |
| 자금투입대비 순손익률 | `순손익 합계 ÷ 최대 동시 투입자금 × 100` |

### 다운로드

- **CSV**: `[종목별 요약]` + `[거래 상세]`
- **Excel**: 시트 `종목별요약`, `거래상세`

## bollinger_candle_with20 (변형 버전)

원본과 동일 전략에 **기준캔들 SMA20 하락 필터**만 추가한 버전입니다.

| 사이드바 | 동작 |
|----------|------|
| **20일선 하락반영 ON** | 당일 SMA20 < 전일 SMA20 이면 기준캔들 탈락 |
| **OFF** (기본) | 20일선 조건 미적용 (원본과 동일) |

- 종가 단순이동평균 **SMA20** (볼린저 기간과 독립)
- 저점캔들에는 영향 없음
- 실시간·시뮬레이션 모두 적용

자세한 내용은 [`bollinger_candle_with20/README.md`](bollinger_candle_with20/README.md)를 참고하세요.

# 볼린저밴드 + 저점캔들 돌파 양봉 자동매매

키움증권 REST API를 이용한 **볼린저밴드 하단 + 240일선 저점캔들 돌파 양봉** 전략의 실시간 자동매매 및 백테스트(시뮬레이션) 프로그램입니다.  
Streamlit 웹 UI로 파라미터 설정, 종목 관리, 결과 분석을 한 화면에서 수행할 수 있습니다.

---

## 주요 기능

| 구분 | 기능 |
|------|------|
| **실시간 자동매매** | 다종목 동시 모니터링, 상태 머신 기반 분할 매수·익절·손절 |
| **시뮬레이션** | 과거 일봉 데이터 백테스트, 종목별·포트폴리오 단위 손익 분석 |
| **종목 입력** | 종목코드 직접 입력 또는 종목명 txt 파일 업로드 (시뮬 실행 시 자동 코드 변환) |
| **시세 구분** | KRX 정규장 / 통합시세(KRX+NXT) 선택 |
| **240일선 필터** | 디폴트 / 240선추세(3·7·10·20일 연속 상승) |
| **자금 분석** | 최대 동시 투입자금, T+3 결제 반영 권장 계좌 잔고, 자금투입대비 순손익률 |

## 설치 방법

### 1. 저장소 클론

```powershell
git clone https://github.com/shanykim9/bol_low_candle.git
cd bol_low_candle
```

### 2. 가상환경 생성 (권장)

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 3. 패키지 설치

```powershell
pip install -r requirements.txt
```

### 4. 환경변수 설정

`.env.example`을 복사하여 `.env` 파일을 만든 뒤 실제 값을 입력합니다.

```powershell
copy .env.example .env
```

`.env` 예시:

```
APP_KEY=발급받은_앱키
APP_SECRET=발급받은_앱시크릿
ACCOUNT_NO=1234-5678-90
```

> **주의:** `.env` 파일에는 API 인증정보가 포함됩니다. GitHub 등 외부에 업로드하지 마세요.

사이드바 하단 **엔진 버전**으로 현재 코드 버전을 확인할 수 있습니다.

---

## 사용 방법

### 실시간 자동매매

1. 사이드바 **운영 모드** → `실시간 자동매매` 선택
2. 종목코드 직접 입력 후 **종목 확인**, 또는 txt 파일 업로드
3. 시세 구분, 지표, 투자금액, 손절·익절 파라미터 설정
4. **▶ 시작** 클릭 → 종목별 상태·이벤트 로그 확인
5. **■ 중지** 로 매매 엔진 종료

### 시뮬레이션 (백테스트)

1. 사이드바 **운영 모드** → `시뮬레이션` 선택
2. 종목 직접 입력(종목 확인) 또는 **종목명 txt 파일 업로드**
3. **▶ 시뮬레이션 실행** 클릭  
   - 파일 업로드 모드: 종목명 → 종목코드 **자동 변환** 후 시뮬레이션 진행
4. 결과 확인
   - 종목별 요약 (매수·매도 횟수, 수익·손실·순손익)
   - 포트폴리오 자금 분석 (최대 동시 투입자금, 권장 계좌 잔고, **자금투입대비 순손익률**)
   - 상세 거래 내역, CSV 다운로드

### 종목명 텍스트 파일 형식

한 줄에 1개, 또는 쉼표·탭·세미콜론으로 구분할 수 있습니다.

```
삼성전자
SK하이닉스, NAVER
카카오; 현대차
```

> 종목코드가 아닌 **종목명**을 입력합니다.

## 전략 요약

| 항목 | 내용 |
|------|------|
| 저점캔들 | 저가 ≥ 240일선 AND 저가 ≤ 볼린저밴드 하한선 (6개월~5년 범위 탐색) |
| 기준캔들 | 양봉 AND 종가 ≥ 저점캔들 고가 |
| 매수 Case A | 기준캔들 거래량 > 저점캔들 × 300% → 즉시 1차 매수 |
| 매수 Case B | 기준캔들 거래량 ≤ 저점캔들 × 300% → 2·3차 분할 매수 대기 |
| 매수포기 | 대기 중 현재가 > 저점캔들 저가 × (1 + abandon%) |
| 손절 | 기준저가 또는 1차 매수가 대비 -5/10/15% |
| 1차 익절 | 평균단가 대비 +15~50% (5% 단위) → 50% 매도 |
| 2차 익절 | 평균단가 대비 +20~60% (5% 단위, 1차보다 높음) → 잔여 50% 매도 |
| 트레일링 스탑 | 최근 익절가 대비 -5% 하락 → 잔량 전량 매도 |

볼린저밴드는 영웅문4와 동일하게 **모집단 표준편차(ddof=0)** 를 사용합니다.

## 시뮬레이션 지표 설명

| 지표 | 설명 |
|------|------|
| 최대 동시 투입자금 | 기간 중 동시에 묶인 매수금의 최대값 (실제 필요 자금의 기준) |
| 권장 계좌 잔고 | T+3 거래일 결제 대기를 반영한 권장 예수금 |
| 자금투입대비 순손익률 | `순손익 합계 ÷ 최대 동시 투입자금 × 100` |

## 주의사항

- 본 코드는 **교육·연구 목적**으로 작성되었습니다.
- 실제 매매에 사용 시 발생하는 손실에 대해 개발자는 책임지지 않습니다.
- 키움증권 REST API 엔드포인트·파라미터는 [키움증권 Open API+ 개발자 센터](https://apiportal.kiwoom.com)에서 최신 문서를 확인하세요.
- 실전 투자 전 **모의투자 계좌**로 충분히 검증하세요.
- `config.py`의 `BASE_URL`을 모의투자 URL로 변경하면 모의 API를 사용할 수 있습니다.
